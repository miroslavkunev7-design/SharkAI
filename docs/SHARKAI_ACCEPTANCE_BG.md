## Абонаменти и съхранение

Нов платен Ultra период се активира от подписано Stripe събитие с потвърдена платена фактура. Ползват се началната и крайната дата от фактурата. SharkAI не налага собствен токенов лимит за действащ Ultra. Доставчикът прилага своите технически ограничения. Съществуващите записани роли и планове се четат без подмяна. Администраторският акаунт не минава през Checkout и webhook-ът не прилага плащане към него.

Добавъчните SQL файлове са в `prisma/upgrade/`. Архивите на новите проекти и разговорите имат изрична собственост. За файлове от стари разговори миграцията запазва достъпа, когато може да докаже един собственик. За стари файлове без доказуем собственик е необходима надеждна връзка с акаунта. Данните на общата гост сесия не се предоставят за частна история.

## Проверки на клона

- `npm run build` и `npx tsc --noEmit --incremental false` преминаха.
- `npm test` срещу production build с тестов акаунт мина 10 от 10 проверки.
- `SHARKAI_TEST_CHAT_PROVIDER=1 node scripts/test-workspace.cjs` мина със самостоятелна база, два тестови акаунта и реален локален модел. Покрива и чужди файлове, проекти, разговори и ZIP.
- `SHARKAI_TEST_BILLING=1 npx tsx scripts/test-billing.ts` мина с PostgreSQL и подписани Stripe fixtures. HTTP контролите отказаха неподписан потребител, невалиден план, липсваща Stripe конфигурация и опит за Checkout с ADMIN.
- Трите SQL файла минаха върху предишната схема с тестови данни. Prisma diff не показа разлика спрямо модела. Съществуващите ADMIN/FREE и USER/ULTRA записи се запазиха.
- Самостоятелният `npm run lint` поиска първоначална ESLint конфигурация. В репото няма такава и отделна lint проверка не е отчетена като премината.

## Конфигурация и предаване

- Web използва `POSTGRES_PRISMA_URL`, `POSTGRES_URL_NON_POOLING`, `JWT_SECRET` и `NEXT_PUBLIC_APP_URL`. Примерните имена и настройки са в `.env.example`.
- AI чатът използва `SHARKAI_USE_PAID_AI` и разрешен `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `AI_GATEWAY_API_KEY` или настроен OpenAI-съвместим Chat Completions адрес. Инструментите на OpenAI имат отделно изискване за хоствана функционалност и разрешени API възможности.
- Месечните плащания изискват `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `STRIPE_PRO_PRICE_ID`, `STRIPE_ULTRA_PRICE_ID` и webhook към тестовата или работната услуга. Настройки или плащания в работна Stripe среда не са използвани за приемането.
- Хостваната страница за изтегляне изисква `INSTALLER_DOWNLOAD_URL` към официалното копие на същата версия. `INSTALLER_SIZE_MB` е по избор.
- GitHub отхвърли създаването на отдалечен клон както през Git, така и през конектора с HTTP 403. Локалният клон съдържа промените за преглед. Windows workflow е включен в този клон.
